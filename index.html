00

Persiapan Lingkungan & Web Server XAMPP

Sebelum menyentuh baris kode Laravel, pastikan web server dan database engine lokal sudah berjalan aktif:

  1. Buka aplikasi XAMPP Control Panel pada komputer pengujian.
  2. Klik tombol Start pada modul Apache (default port: 80, 443).
  3. Klik tombol Start pada modul MySQL (default port: 3306).
  4. Pastikan indikator kedua modul berubah menjadi hijau. Jika port 3306 bentrok, pastikan tidak ada service MySQL instance lain yang sedang berjalan.
Tips Ujian Serkom:

Anda sebenarnya tidak perlu membuka phpMyAdmin secara manual untuk membuat database. Laravel 11 otomatis menawarkan membuatkan database saat perintah php artisan migrate dijalankan untuk pertama kalinya.

Eksekusi Perintah Scaffolding Model & Controller

Jalankan 3 baris perintah artisan vital di terminal VS Code secara berurutan:

# 1. Master Menu Makanan (Model + Migration + Controller Resource)
php artisan make:model Food -mcr

# 2. Transaksi Induk Pesanan (Model + Migration + Controller Resource)
php artisan make:model Order -mcr

# 3. Rincian Item Transaksi (Model + Migration saja)
php artisan make:model OrderDetail -m

Mengapa OrderDetail hanya menggunakan flag -m?

Karena rincian item pesanan dibuat langsung di dalam proses checkout pada OrderController. Tidak dibutuhkan controller terpisah untuk rincian detail pesanan, sehingga cukup migration dan model saja.

03

Cetak Biru Database Migration (3 Tabel Utama)

database/migrations/xxxx_create_foods_table.php 
Schema::create('foods', function (Blueprint $table) {
    $table->id();
    $table->string('name');
    $table->enum('category', ['Makanan', 'Minuman', 'Cemilan']);
    $table->decimal('price', 10, 2);
    $table->text('description')->nullable();
    $table->string('image')->nullable();
    $table->timestamps();
});
database/migrations/xxxx_create_orders_table.php 
Schema::create('orders', function (Blueprint $table) {
    $table->id();
    $table->string('customer_name');
    $table->string('table_number');
    $table->decimal('total_price', 12, 2)->default(0);
    $table->string('status')->default('Pending'); // Hindari enum kaku agar bebas error kapitalisasi
    $table->timestamps();
});
database/migrations/xxxx_create_order_details_table.php 
Schema::create('order_details', function (Blueprint $table) {
    $table->id();
    // Foreign Key ke orders
    $table->foreignId('order_id')->constrained('orders')->onDelete('cascade');
    // Foreign Key ke foods
    $table->foreignId('food_id')->constrained('foods')->onDelete('cascade');
    $table->integer('quantity');
    $table->decimal('subtotal', 12, 2);
    $table->timestamps();
});
Eksekusi migrasi di terminal: php artisan migrate. Jika muncul pertanyaan pembuatan database 'pesanmakan', ketik yes lalu Enter.

if ($request->hasFile('image')) {
    $validated['image'] = $request->file('image')->store('foods', 'public');

    if ($food->image && Storage::disk('public')->exists($food->image)) {
        Storage::disk('public')->delete($food->image);
    }
    $validated['image'] = $request->file('image')->store('foods', 'public');
}
$food->update($validated);

// Destroy (Hapus foto fisik saat hapus data)
if ($food->image && Storage::disk('public')->exists($food->image)) {
    Storage::disk('public')->delete($food->image);
}
$food->delete();
08

Katalog Customer & Eksekusi DB::transaction

Method checkout pada OrderController::store wajib dibungkus transaksi atomik:

public function store(Request $request)
{
    $request->validate([
        'customer_name' => 'required|string|max:255',
        'table_number'  => 'required|string',
        'items'         => 'required|array',
    ]);

    $orderedItems = array_filter($request->items, fn($qty) => (int)$qty > 0);
    if (empty($orderedItems)) {
        return back()->with('error', 'Pilih minimal satu menu makanan!');
    }

    $order = DB::transaction(function () use ($request, $orderedItems) {
        $order = Order::create([
            'customer_name' => $request->customer_name,
            'table_number'  => $request->table_number,
            'total_price'   => 0,
            'status'        => 'Pending',
        ]);

        $grandTotal = 0;
        foreach ($orderedItems as $foodId => $qty) {
            $food = Food::findOrFail($foodId);
            $subtotal = $food->price * $qty;
            $grandTotal += $subtotal;

            OrderDetail::create([
                'order_id' => $order->id,
                'food_id'  => $food->id,
                'quantity' => $qty,
                'subtotal' => $subtotal,
            ]);
        }

        $order->update(['total_price' => $grandTotal]);
        return $order;
    });

    return redirect()->route('customer.index')->with('success', 'Pesanan berhasil dibuat!');
}

Monitoring Admin & Update Status PATCH

Ambil data dengan Eager Loading dan perbarui status pesanan seketika dari dropdown:

// 1. Controller: Eager Loading Anti N+1
public function adminDashboard()
{
    $orders = Order::with('orderDetails.food')->latest()->get();
    return view('dashboard', compact('orders'));
}

// 2. Controller: Update Status PATCH
public function updateStatus(Request $request, $id)
{
    $request->validate(['status' => 'required|string']);
    $order = Order::findOrFail($id);
    $order->update(['status' => ucfirst(strtolower($request->status))]);
    return back()->with('success', 'Status pesanan berhasil diperbarui!');
}

Di file Blade dashboard, form select dapat melakukan auto-submit saat diganti:
